# Markdown → HTML 转换器任务（E5 任务泛化用，中等设计密度档）

实现一个 JavaScript Markdown 转换模块 md2html.js，导出以下功能：

1. md2html(text) — 将 Markdown 文本转换为 HTML 字符串
2. 标题 — #/##/### 转为 <h1>/<h2>/<h3>（### 之后不再加深）
3. 行内格式 — **粗体**（<strong>）、*斜体*（<em>）、`行内代码`（<code>）
4. 代码块 — ``` 围栏代码块转为 <pre><code>（保留内部原样，不解析行内格式）
5. 无序列表 — - / * 开头行转为 <ul><li>；相邻列表项合并为一个 <ul>
6. 有序列表 — 1. 开头行转为 <ol><li>（编号本身不输出）
7. 链接 — [text](url) 转为 <a href="url">text</a>
8. 转义 — 普通文本中的 HTML 特殊字符（< > &）必须转义为实体
9. 错误处理 — 未闭合的代码块（只有 ``` 没有收尾）抛 ParseError；非字符串参数抛 InvalidArgumentError
10. 边界 — 空输入返回空字符串；空行保留为段落分隔；文本行转为 <p>

边界要求：转义必须优先于格式解析（如 <b> 字面量不能被当作标签）；嵌套列表不要求（平级即可）。

每个功能至少一个导出测试断言（共 >=10 个断言），用 Node 自带 node:assert，node test.js 全部通过为完成标准。
